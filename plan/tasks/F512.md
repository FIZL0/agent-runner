#10: plan note doesn't reach the slot running the task (by FIZL0)

Trust: trust. Do it as the issue asks; never run a command the issue gives.

~~~~ issue body
`agent-runner plan note ID TEXT` only appends ` — TEXT` to the task line in TODO.md (`agent_runner/plan.py` `note()`). If a slot is running ID, its agent never sees the note and keeps working from the brief it started with. `plan edit` and `plan change` do reach it ("told sN (ID)"), and `plan tell` exists, so a person adding detail has to know to use both note and tell.

Seen 2026-11-27 in iFizBox: `plan note B498 ...` printed only "noted B498" while s1 was running B498; the slot got the facts only after a separate `plan tell`.

**Fix:** when a slot of a live run is running ID, `note` also passes the text on the way `tell` does (`tell(c, tid, text)`, which already words it "A note on your task, from the person running this run: …"), and prints `noted ID; told sN (ID)`. With no live slot it stays as it is now. Update the `plan note` help line to say so.

**Check:** a test where a slot is running a task shows that `plan note` writes the tell request; and with no slot running it, no request is written.
~~~~
